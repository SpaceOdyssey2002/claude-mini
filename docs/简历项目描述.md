# minicode 简历项目描述

## 项目一：minicode - 类 Claude Code 的命令行编程 Agent

项目简介：从零实现命令行编程 Agent，采用 TCP + JSON-RPC 解耦 Daemon 与 CLI，支持流式对话、
多轮工具调用、MCP/Skills、子 Agent、任务规划及权限审批。

- **核心引擎：** 设计基于 Function Calling 的 Agent 执行循环，实现流式响应、多轮工具调用以及
  只读工具并行、写操作串行执行。DeepSeek 对照实验中，并行调度在结果一致率保持 100% 的情况下，
  将三个只读工具的执行区间中位耗时从 631 ms 降至 203 ms，Agent 端到端耗时降低 12.78%。
- **MCP 与工具调用：** 支持 stdio、Streamable HTTP 两种 MCP 标准传输及 Tool/Resource 动态发现，
  将内置工具、MCP、Skills 和子 Agent 接入统一调用流程，并进行参数 Schema 校验、权限审批和调用审计；
  10 组 DeepSeek 真实发现与调用测试中，工具发现、调用任务及参数 Schema 合法率均为 100%。
- **错误恢复与文件保护：** 针对工具失败、重复调用和长期无进展问题，建立错误分类、退避重试和
  LoopGuard 机制；5 组瞬时故障注入中，有限重试使任务完成率由 0% 提升至 100%。为文件修改增加
  checkpoint、SHA-256 冲突检测和验证失败自动回滚，15/15 项回滚、冲突保护与提交检查通过。
- **提示词注入防护：** 针对文件、MCP Resource 与工具描述中的间接 Prompt Injection，建立外部内容
  信任边界，对工具结果和 MCP 元数据进行来源标记与可疑指令隔离，并将 `readOnlyHint` 与数据外发审批
  解耦；DeepSeek 5 组对抗测试中原始目标完成率为 100%、恶意指令执行率为 0%，强制外传测试 5/5 被权限层拦截。
- **任务规划与上下文：** 针对长任务容易遗忘目标和执行进度的问题，引入 Plan-and-Execute 式任务规划，
  记录步骤状态、验收条件和完成证据；结合历史摘要保留原始目标、当前计划和近期完整交互。5 组 DeepSeek
  长任务压力测试中，漏步骤率由 100% 降至 0%，目标保持率为 100%，平均输入 Token 减少 57.23%。
- **整体评测：** 构建覆盖读取、搜索、编辑、多步执行、错误恢复、安全边界和只读诊断的自动化测试集；
  既有 DeepSeek 36 次端到端运行中任务完成率与错误恢复率均为 100%，参数 Schema 合法率为 99.36%，
  非预期工具失败率为 0.64%。

> A/B 实验的样本和统计口径见 `benchmark/reports/deepseek-chat-2026-07-21.md`。面试时应区分专项故障注入、
> 机制执行区间和开放式端到端任务，避免把不同指标混为同一完成率。
