# 代码审查

审查代码时，按以下维度逐项检查，每条发现给出「文件:行号 + 问题 + 建议」：

1. **正确性**：边界条件、空值、异步竞态、错误处理是否遗漏
2. **安全**：注入、路径越界、密钥硬编码、未校验的外部输入
3. **可读性**：命名、函数长度、重复代码、注释是否到位
4. **性能**：不必要的循环/拷贝、可缓存的计算、N+1 调用

输出格式：

- 先给一句总体结论（可合并 / 需修改）
- 再按维度列出具体发现，每条标注严重程度（高/中/低）
- 不确定的也列出来，但标注「待确认」，不要为了显得保守而漏报

只指出问题与建议，除非用户明确要求，否则不直接改代码。
